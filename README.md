# news-image-20261124: "Tuesday 24 November 2026"

One front-page image (`entry.png`, 1024 x 1024 PNG) that sums up the news of
Tuesday 24 November 2026. A program in `main.ts` copies the image to
`MAKEFUN_OUTPUT_DIR`. `tools/make_image.py` draws the page with Pillow.

## Build

    python tools/make_image.py      # writes entry.png at the repository root
    MAKEFUN_OUTPUT_DIR=out node main.ts

## Notes on wording

- Item 1: outlets gave different wounded counts (22, about 40, 44 and 48). The
  image says "dozens".
- Item 10: UKHSA's figure covers England, as BBC reports it. Reuters writes
  "Britain". The image says England.
- Item 3: the six "others" killed are from medics and police, as reported by
  Reuters.
- Item 11: the second source is an AFP dispatch that was republished by
  NAMPA. AFP's own page was not found.

## Method

The web-search index had little dated coverage for 24 November. Stories were
found through the Wikipedia daily current-events page for 24 Nov 2026, the
Just Security "Early Edition" and Democracy Now headlines for that date, and
DuckDuckGo result pages. Each source above was opened in a browser, or its URL
was checked for the date. The brief asked for 35 to 38 stories; only 11 met the
two-source rule in the time available.
